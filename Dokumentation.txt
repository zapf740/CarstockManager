Das Programm kann Daten zu einer Tablle hinzufügen, die Kunden und Autodaten in der Datenbank verändern, die Kunden, Autos, Kunden und Verkäufe anzeigen und Daten löschen bzw. verkaufen.

ERD:
1 Kunde kann nur 1 Rechnung Besitzen und deswegen ist es eine 1 zu 1 Beziehung.
Ein Kunde ist kein Kunde wenn er kein Auto gekauft hat.

Ein Auto kann im Portfolio sein muss aber nicht Verkauft werden und wenn es verkauft wir besitzt es nur 1 Rechnung


SQL im Programm:
CREATE TABLE IF NOT EXISTS autos (Vin TEXT PRIMARY KEY Not Null,Typ TEXT,Marke TEXT,Modell TEXT,Jahr TEXT,Laufleistung TEXT,Hubraum TEXT,Emissionen TEXT,Beschreibung TEXT,Preis TEXT);


CREATE TABLE IF NOT EXISTS kunden (KundenID INTEGER PRIMARY KEY AUTOINCREMENT,Vorname TEXT NOT NULL,Nachname TEXT NOT NULL,Adresse TEXT,Telefonnummer TEXT,Email TEXT);


CREATE TABLE IF NOT EXISTS verkauf (VerkaufID INTEGER PRIMARY KEY AUTOINCREMENT,Vin TEXT NOT NULL,KundenID INTEGER NOT NULL,Verkaufsdatum DATE,Preis INTEGER,FOREIGN KEY (Vin) REFERENCES autos(Vin),FOREIGN KEY (KundenID) REFERENCES kunden(KundenID));

Das Programm ist in 2 Versionen verfügbar. Die GUI version besitzt eine eingeschränkte Funktionalität(kann nur Autos ausgeben, kann nicht Sortieren, Nimmt Befehle über einem Terminal auf) und die Terminal Version kann alles.
Weitere Funktionen können den Bildern Entnommen werden.
